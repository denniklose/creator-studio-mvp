## Lokal öffnen

1. Terminal öffnen.
2. In den Projektordner wechseln:

   ```bash
   cd "/Users/tim/Documents/Codex/2026-09-01/jo-ja-ich-wei-ja-auch"
   ```

3. Oberfläche starten:

   ```bash
   npm run dev
   ```

4. Die im Terminal genannte lokale Adresse im Browser öffnen.

## Was bereits funktioniert

- Creator-Profil und Projektkontext lokal speichern
- sechs Szenen auswählen und Texte bearbeiten
- Entwicklungspartner-Vorschläge übernehmen
- lokale Vorschau mit ehrlicher Kostenanzeige erstellen
- mobile Prüfliste und Freigabe bis zum Exportstatus
- Projekt als bearbeitbare JSON-Datei herunterladen
- Bereiche Heute, Bibliothek, Analyse, Studio und Exporte

## Bewusste Grenze des MVP

YouTube, OpenAI, Video- und Stimmenanbieter sind noch nicht live verbunden. Die Oberfläche kennzeichnet deshalb Musterdaten und erzeugt kein vorgetäuschtes MP4. Zugangsdaten und kostenpflichtige Aufrufe gehören in einem nächsten Schritt auf eine abgesicherte Server-Schicht.
